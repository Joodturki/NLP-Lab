# Lab 9: Named Entity Recognition

This lab uses spaCy to identify and visualize named entities in text.

- Task 1: Recognize entities in a user-entered sentence.
- Task 2: Add missing entities, count PERSON and ORG entities, and visualize them.
- Task 3: Train a custom NER model for 20 iterations, save it, and test it.

Requirements: Python, spaCy, and en_core_web_sm.

Run the notebook cells from top to bottom.
