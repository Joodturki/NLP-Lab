# NLP Lab

This lab applies different NLP techniques to text data.

## Tasks

1. Calculate sentence similarity using Cosine Similarity.
2. Identify important words using TF-IDF.
3. Preprocess the Simpsons dataset and create a Skip-gram Word2Vec model.
4. Find words similar to Homer, Marge, and Bart.
5. Find the odd word in different word groups.

## Libraries

* Pandas
* NLTK
* Gensim
* Scikit-learn
* re

## Dataset

`simpsons_script_lines.csv`
